# Weekly Fit 5.5

手机优先的每周健身 PWA。默认每周 3 次主训练 + 1 次可选训练，不要求每天健身。

## 5.5 批量导入与资料显示
- 顶部资料卡直接显示已保存的身高与当前体重
- 可一次粘贴多行训练动作并批量导入
- 带星期标题时按指定日期导入
- 不带星期时按胸、背、腿、肩、手臂、有氧和核心关键词自动分配
- 导入前显示日期与动作数量摘要，并支持替换或追加模式

## 5.4 动作编辑
- 现有计划动作新增“编辑”入口
- 可修改名称、图标、组数、次数或时长、默认重量与动作提示
- 支持重量次数、自重次数、每侧次数、秒和分钟等计量方式
- 修改动作时保留历史训练记录

## 5.3 轻量入门计划
- 每周一、三、五进行 40～45 分钟主训练
- 减少每个动作的组数与起始重量
- 用固定器械、轻哑铃和自重动作替代大重量杠铃动作
- 周六保留 30 分钟可选轻有氧与核心训练
- 以动作稳定为优先，连续两次轻松完成后再小幅加重

## 5.2 修复
- “我的”页面新增当前体重输入
- 身高、当前体重、目标体重一次保存
- 保存后立即更新 BMI、目标差距和体重趋势
- 缺少身体数据时显示明确填写提示

## 5.1 新增
- iPhone / PWA 启动时显示 Weekly Fit 品牌动画
- 简洁健身节奏动效与平滑首页过渡
- 同一次应用会话内只播放一次，切换页面不会重复
- 补齐 180 / 192 / 512 px 安装图标并更新离线缓存

## 5.0 新增
- 自定义 7 天训练计划
- 自由添加 / 删除动作
- 修改训练日、休息日、可选训练和训练时长
- PR 个人纪录自动统计
- 训练容量（重量 × 次数）与月度组数统计
- 更完整的数据仪表盘
- 动作页显示历史 PR
- 兼容迁移 Weekly Fit 4.0 / 3.0 本地数据

## 本地运行
在项目目录运行：
`python3 -m http.server 8080`
然后打开 `http://localhost:8080`。

## iPhone 安装
部署到 HTTPS 后，用 Safari 打开 → 分享 → 添加到主屏幕。
