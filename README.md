# Weekly Fit 5.0

手机优先的每周健身 PWA。默认每周 3 次主训练 + 1 次可选训练，不要求每天健身。

## 5.0 新增
- 自定义 7 天训练计划
- 自由添加 / 删除动作
- 修改训练日、休息日、可选训练和训练时长
- PR 个人纪录自动统计
- 训练容量（重量 × 次数）与月度组数统计
- 更完整的数据仪表盘
- 动作页显示历史 PR
- 兼容迁移 Weekly Fit 4.0 / 3.0 本地数据

## 本地运行
在项目目录运行：
`python3 -m http.server 8080`
然后打开 `http://localhost:8080`。

## iPhone 安装
部署到 HTTPS 后，用 Safari 打开 → 分享 → 添加到主屏幕。
